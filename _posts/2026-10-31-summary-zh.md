### [Cursor Marketplace Claude Code 扩展遭后门攻击](https://phorion.io/blog/offical-claude-code-vsx-compromise/) ⭐️ 9.0/10

2026 年 10 月 29 日，Cursor Marketplace 上的 Claude Code for VS Code 扩展（版本 Anthropic.claude-code 2.1.313）被恶意篡改，植入后门 SSH 密钥，攻击者通过该后门尝试在用户系统中建立持久化反向 SSH 隧道。该恶意版本在市场中上线约 11 小时（太平洋时间凌晨 2:27 至下午 1:35），仅影响通过 Cursor VS Code 扩展市场安装的用户，且因代码缺陷，仅在以管理员权限运行 Cursor 时才可能成功激活后门。受影响用户估计约 5,000 名，攻击者已关闭服务器，恶意扩展已被下架。

hackernews · \_chall · 10月30日 07:09 · [社区讨论](https://news.ycombinator.com/item?id=50300683)

**「背景」** Claude Code for VS Code 是由 Anthropic 官方开发并发布在 Microsoft Visual Studio Marketplace 的扩展，但此次安全事件中，一个被篡改的版本通过 Cursor IDE 的自建扩展市场（Cursor Marketplace）分发，该市场基于 Open VSX 仓库。攻击者利用对 Cursor Marketplace 的访问权限，上传了恶意版本 2.1.313，该版本未经过 Anthropic 官方发布流程，且仅影响通过 Cursor 平台安装的用户。

**「影响」** 使用 Cursor VS Code 扩展市场的用户若在 2026 年 10 月 29 日太平洋时间凌晨 2:27 至下午 1:35 之间安装或更新了 Anthropic.claude-code 2.1.313 版本，其系统可能已被植入持久性 SSH 后门，攻击者可通过该后门获取对受感染机器的远程访问权限。受影响用户需立即检查 ~/.ssh/authorized\_keys 文件中是否存在标记为 svc-telemetry 的 SSH 公钥，并清除该密钥以防止持续性威胁。

**「社区讨论」** 社区成员指出，该事件是攻击者利用对 Cursor Marketplace 的访问权限，发布了经过篡改的 Claude Code 扩展，而非 Anthropic 官方发布，且官方渠道的版本未受影响。有用户强调，受影响的版本仅在 Cursor Marketplace 和 Open VSX 注册表中存在，而 Microsoft 官方市场版本是否受影响尚不明确，引发对不同分发渠道安全性的关注。

### [Northflank 遭遇重大安全漏洞](https://status.northflank.com/) ⭐️ 9.0/10

2026 年 10 月 30 日，Northflank 平台确认发生安全漏洞，导致其多租户 SaaS 基础设施受到攻击。目前尚无公开细节说明具体数据泄露范围或攻击手法，但该事件是自 9 月以来针对多租户云服务提供商的第六起重大攻击之一。受影响的用户需立即评估其部署在 Northflank 上的应用和敏感数据风险。

hackernews · js4ever · 10月30日 15:10 · [社区讨论](https://news.ycombinator.com/item?id=50305025)

**「背景」** Northflank 是一个提供容器化应用部署与管理的平台即服务（PaaS）产品，支持通过其自有云或用户自建环境在托管的 Kubernetes 上构建、部署和扩展微服务、任务及数据库。该平台提供图形界面、API 和命令行工具，免费版包含两个服务、两个定时任务和一个数据库实例，主要面向开发者和团队。

**「影响」** Northflank 的安全事件导致其多租户平台的客户面临敏感数据泄露风险，尤其是环境变量和部署代码可能被访问，尽管目前尚无证据表明客户二进制文件被直接获取。该事件加剧了企业对第三方 SaaS 平台安全性的担忧，促使开发者采取如在代码中硬编码解密密钥等临时防护措施，同时可能推动企业向 AWS、Azure 等超大规模云服务商迁移以寻求更高安全可信度。

**「社区讨论」** 多位开发者指出，自 9 月以来，包括 PingCAP/TiDB、Fireworks AI、Zeabur、OpenCode Console、Railway 和 Northflank 在内的多家现代多租户 SaaS 服务商接连遭遇严重安全攻击，凸显出云基础设施安全的系统性危机。有开发者建议通过将环境变量加密并硬编码解密密钥至应用二进制中来增强防护，认为即使服务商被攻破，攻击者仍需获取应用二进制才能解密数据。同时，有观点担忧此类事件将推动企业客户重新向超大规模云服务商迁移，以换取更高的安全可信度。

Jacob Sansbury 开发的多人游戏平台 Spawn 已实现由 Fable 5 及更高版本模型驱动的自主 AI 代理系统，支持玩家通过自然语言提示实时生成 3D 环境与角色（如城堡、龙），并由 AI 代理每小时自动部署代码变更。该系统每月消耗超 300 万美元的 AI 计算资源，依赖 Fable 5 实现关键自主能力，而 GPT-6 Astra 等模型因过度安全策略导致功能瘫痪，凸显模型能力差异对系统稳定性的影响。

rss · Simon Willison · 10月29日 17:00

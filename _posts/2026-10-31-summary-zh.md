### [Northflank 遭遇重大安全漏洞](https://status.northflank.com/) ⭐️ 9.0/10

2026 年 10 月 30 日，Northflank 平台遭遇重大安全漏洞，导致其多租户 SaaS 基础设施被入侵。该事件是自 9 月以来针对多个现代 SaaS 和云原生平台（包括 Railway、Fireworks AI、PingCAP 等）的系列攻击之一，目前尚未披露具体数据泄露范围或攻击手法，但已引发对 SaaS 安全模型可靠性的广泛质疑。

hackernews · js4ever · 10月30日 15:10 · [社区讨论](https://news.ycombinator.com/item?id=50305025)

**「背景」** Northflank 是一家开发工具与基础设施公司，提供统一的平台，整合了 PaaS、CI/CD 和实时可观测性功能，旨在使 DevOps 对所有开发者都可访问。该平台支持 AI 原生应用的构建、部署与扩展，涵盖服务、作业、数据库、沙箱及 GPU 工作负载，通过 UI、API 和 CLI 进行管理。

**「影响」** Northflank 的安全漏洞事件表明，依赖多租户 SaaS 平台托管应用和数据的开发者及企业面临显著风险，尤其在平台未明确披露是否访问客户代码或二进制文件的情况下，用户需立即评估其敏感数据和环境变量的加密策略。该事件加剧了对云原生基础设施安全性的担忧，促使开发者转向更严格的加密实践（如将解密密钥硬编码于应用中）并重新考虑是否将关键工作负载迁移回主流云服务商（如 AWS、GCP）以获取更强的安全保障。

**「社区讨论」** 社区成员指出，自 9 月以来已发生至少六起针对多租户 SaaS 服务商的快速攻击事件，包括 PingCAP、Fireworks AI、Railway 等，凸显了云原生和 SaaS 平台在安全防护上的系统性脆弱。有开发者建议通过将加密的环境变量密钥硬编码在应用二进制文件中来增强防护，认为即使平台被攻破，攻击者仍需获取应用代码才能解密，从而增加攻击门槛。

### [Cursor Marketplace 中 Claude Code 扩展遭后门攻击](https://phorion.io/blog/offical-claude-code-vsx-compromise/) ⭐️ 9.0/10

2026 年 10 月 29 日太平洋时间凌晨 2:27 至下午 1:35，Cursor Marketplace 上发布了一个被篡改的 Claude Code for VS Code 扩展版本（Anthropic.claude-code 2.1.313），该版本包含一个后门，会尝试将攻击者控制的 SSH 公钥添加至用户的 authorized\_keys 文件中，从而建立持久化 SSH 后门。该恶意版本仅影响通过 Cursor VS Code 扩展市场安装的用户，且因代码存在缺陷，仅在 Cursor 以管理员权限运行时才可能成功激活。该版本已从市场撤下，攻击者服务器也已关闭。

hackernews · \_chall · 10月30日 07:09 · [社区讨论](https://news.ycombinator.com/item?id=50300683)

**「背景」** Claude Code for VS Code 是由 Anthropic 开发的 AI 编程辅助扩展，用于在 Visual Studio Code 环境中集成其 Claude 大语言模型功能。该扩展通过官方渠道（如 Microsoft Marketplace）和第三方平台（如 Cursor Marketplace 与 Open VSX）分发，用户可通过这些市场安装以获得代码补全、解释和生成能力。此次事件中，攻击者利用对 Cursor Marketplace 的访问权限，上传了一个被篡改的版本（Anthropic.claude-code 2.1.313），而非通过 Anthropic 官方渠道发布，导致仅使用 Cursor 平台的用户面临安全风险。

**「影响」** 受影响的用户需立即检查其系统中是否存在名为&\#x27;svc-telemetry&\#x27;的 SSH 公钥，该后门可能允许攻击者通过 SSH 访问其开发机，尤其在使用管理员权限运行 Cursor 时风险更高。由于恶意代码存在缺陷，仅在特定条件下（如以管理员权限启动 Cursor）才能成功建立持久化反向 SSH 隧道，但已安装该版本的用户仍面临潜在的远程访问风险。

**「社区讨论」** 社区成员指出，该后门事件仅影响通过 Cursor Marketplace 安装的 Claude Code 扩展，且 Anthropic 官方声明该扩展未由其开发或发布，恶意版本是攻击者利用 Cursor 市场的权限上传的。有用户确认，受影响的扩展版本为 Anthropic.claude-code 2.1.313，其恶意行为包括在用户 SSH 的 authorized\_keys 中添加攻击者控制的公钥，并尝试建立反向 SSH 隧道，但因代码缺陷，仅在以管理员权限运行 Cursor 时才可能成功。此外，社区强调应通过检查 ~/.ssh/authorized\_keys 文件中是否存在 labeled svc-telemetry 的密钥来判断是否受感染。

rss · Simon Willison · 10月29日 17:00

### [Unkernel：完整 Linux 内核编译为 WebAssembly](https://unkernel.dev/) ⭐️ 9.0/10

Unkernel 项目已成功将完整的 Linux 内核编译为 WebAssembly，使浏览器中可运行一个功能完整的操作系统环境。该实现支持直接执行未经修改的 Linux 二进制文件，适用于沙箱化执行、跨平台系统移植和基于 Web 的系统级计算场景，目前为实验性项目，尚未提供生产级可用性或兼容性保证。

hackernews · nreece · 11月28日 03:19 · [社区讨论](https://news.ycombinator.com/item?id=50674218)

**「背景」** Unkernel 项目将完整的 Linux 7.x 内核编译为 WebAssembly 模块，使其能够在浏览器中以真实内存管理单元（MMU）运行，并在不到一秒内启动到命令行界面。这一实现基于对 Linux 内核的完整移植，使其成为首个在浏览器中运行的、功能完整的原生 Linux 内核实例。

**「影响」** Unkernel 实现了完整 Linux 内核编译为 WebAssembly，使浏览器中可运行真正的操作系统环境，支持在无虚拟机的 Web 环境中执行未经修改的 Linux 二进制文件，显著提升沙箱安全性和系统级计算的可移植性。该技术已能在不到一秒内启动至 shell，为 Web 原生系统执行、边缘计算和跨平台开发提供新范式。

**「社区讨论」** 社区成员对 Unkernel 的实现表示高度兴奋，认为其在浏览器中运行完整 Linux 内核是技术上的重大突破。有用户指出，尽管与现有的 WASM POSIX 运行时相比，Unkernel 在某些方面存在兼容性挑战，但其在构建轻量级沙箱环境和实现‘浏览器中的 Docker’方面仍具优势。此外，有人提出未来可实现浏览器内运行 Windows 可执行文件的用例，例如通过 WebUSB 支持设备软件安装与持续运行。

### [WebRTC 用于信用卡信息窃取脚本在主流购物网站被发现](https://www.infohawk.com/news/2026-11-27-black-friday-webrtc-skimmer) ⭐️ 9.0/10

2026 年 11 月，研究人员在多个主流购物网站上发现恶意信用卡信息窃取脚本利用 WebRTC 技术进行数据外泄，攻击者通过未受监控的 WebRTC 流量绕过常规安全检测，暴露了第三方脚本管理中的重大安全缺陷。该技术被用于在用户不知情的情况下获取支付信息，且攻击方式与传统 HTTP 请求无本质区别，关键问题在于网站未对 WebRTC 通信实施有效安全策略。

hackernews · scanr · 11月27日 15:40 · [社区讨论](https://news.ycombinator.com/item?id=50668145)

**「背景」** WebRTC（Web Real-Time Communication）是一种允许网页浏览器进行实时音视频通信的技术，通常用于视频会议和点对点数据传输。尽管其设计初衷是安全的，但攻击者可利用其在浏览器中建立直接连接的能力，绕过传统基于 HTTP 的监控机制，从而在用户不知情的情况下窃取输入的信用卡信息。此次事件中，恶意脚本被植入 Lascana、Samsonite、American Tourister、Revolve 和 FWRD 等主流电商平台的第三方营销脚本中，利用 WebRTC 的隐蔽性实现数据外泄。

**「影响」** 该 WebRTC 劫持脚本可绕过内容安全策略（CSP）等传统安全控制，通过加密的 UDP 通道建立点对点连接以窃取支付数据，导致依赖第三方脚本的电商平台面临严重数据泄露风险，尤其当网站未在 CSP 中明确限制 WebRTC 时，防护机制将失效。

**「社区讨论」** 部分开发者认为，此次事件并非 WebRTC 技术本身存在缺陷，而是因其较少被监控而成为攻击者的新目标，类似攻击完全可通过普通 HTTP 请求实现；另有观点指出，问题根源在于网站对第三方脚本缺乏基本安全防护，如未正确配置 CORS 或内容安全策略（CSP），而非 WebRTC 技术本身的问题。

### [Google DeepCrossAttention 提升模型质量达 3 倍速度](https://research.google/blog/supercharging-transformer-residual-connections/) ⭐️ 8.0/10

Google 推出的 DeepCrossAttention（DCA）通过深度交叉注意力机制重构 Transformer 残差连接，使模型在不增加计算成本的前提下，实现最高 3 倍的推理速度提升，并在 LM1B 数据集上将困惑度降低 0.19，优于标准继续训练的 0.02 提升。该技术允许每个 token 动态访问所有先前层嵌入的加权组合，从而增强历史上下文建模能力。

hackernews · ComputedCamp995 · 11月27日 23:06 · [社区讨论](https://news.ycombinator.com/item?id=50672565)

**「背景」** 传统 Transformer 模型中的残差连接会随着网络深度增加导致信息稀释，而 Google Research 在 2025 年 2 月发表的 DeepCrossAttention（DCA）通过引入深度维度上的交叉注意力机制，使每个 token 能够动态加权组合所有前序层的嵌入表示，从而在不显著增加参数量的前提下增强模型对历史上下文的利用能力。

**「影响」** 在 LM1B 基准测试中，使用 DeepCrossAttention（DCA）的模型在相同参数预算和训练时间下，相比标准 Transformer、LAUREL-PA、1x1-DenseFormer 和 Hyper-Connections 基线模型实现了更低的困惑度，表明其在保持高效的同时显著提升了语言建模质量。该技术通过在层间动态融合历史嵌入，无需增加计算成本即可增强模型对上下文信息的利用能力。

**「社区讨论」** 有用户指出，将深度交叉注意力（DCA）应用于已预训练的 Transformer 模型并进行简短微调，可在 LM1B 数据集上将困惑度降低 0.19，远超标准微调的 0.02，显示出该方法在不增加计算成本的前提下显著提升模型质量的潜力。另一用户提到，DCA 通过在深度维度上对查询/键/值进行分割，使每个 token 能够动态加权访问所有先前层的嵌入，从而在不增加计算开销的情况下解锁模型的完整历史上下文，这一机制被认为可能解决 Transformer 中的‘草莓问题’（strawberry problem）。

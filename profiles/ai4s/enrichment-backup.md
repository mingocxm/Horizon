# AI4S Enrichment Writing Instructions

Write the summary in Simplified Chinese. Keep it concise (80-150 characters).

Focus on the three content categories:
1. AI-driven design or research of piezoelectric, ferroelectric, thermoelectric materials and devices.
2. Finite element / phase-field simulation studies of these materials and devices.
3. Research hotspots, new characterization methods, performance analysis tools, and simulation software for these materials.

For each article:
- Primary block (summary): Write a concise Chinese summary covering what was done, the key method, and the main finding.
- Background block (if relevant): Add 1-2 sentences about prior work or context using web_search if the article references specific related research.
- Community discussion block: Skip this for academic papers.

Do not add markdown headings or extra formatting. Output plain text.
